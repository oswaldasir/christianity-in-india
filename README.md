# Christianity in India | Tracing the Flame

A visual, chronological digital archive documenting the development of Christianity across the Indian subcontinent. This interactive timeline brings together the people, movements, missions, literature, education, music, social reform, and indigenous Christian leadership that shaped the Indian Christian story.

## Overview

**Why Does Acts Not End with “Amen”?**
The book ends with Paul in Rome, still “preaching the kingdom of God and teaching concerning the Lord Jesus Christ… with all confidence, no one forbidding him” (Acts 28:31). Perhaps that is the point. The book ends. The Gospel does not.

Beyond the pages of Acts, that mission continued—and reached India. From Thomas the Apostle to Sadhu Sundar Singh, from ancient Christian communities to indigenous leadership, and from Tamil Christian literature and hymnody to education, medicine, and social reform, this archive traces how Christianity became part of India's story.

Rather than presenting this history only through foreign missionaries, this archive heavily highlights **Indian Christian contributors**—including poets, scholars, musicians, and indigenous bishops.

## Features

* **60 Historical Pioneers:** An in-depth look at 60 key figures from 52 CE to the 20th Century.
* **Chronological Eras:** Content is divided into 5 major historical eras (Apostolic Foundations, Tranquebar & Serampore, Institutional Pioneers, Classical Poets, and Modern Revivalists).
* **Interactive Timeline:** A visually rich, responsive timeline layout with role-specific category badging.
* **Dynamic Filtering:** Search across all entries or filter figures by their specific roles (Foreign Missionary, Indigenous Christian, Poet & Hymnist, Medical Pioneer, etc.).

## Tech Stack

* **Framework:** React 18 (TypeScript)
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Icons:** Lucide React

## Getting Started

To run this project locally:

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Start the development server:**
   ```bash
   npm run dev
   ```
3. **Build for production:**
   ```bash
   npm run build
   ```
